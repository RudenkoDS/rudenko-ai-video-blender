Создай С НУЛЯ в Blender законченный cinematic 3D animation shot длительностью примерно 10–12 секунд.

У тебя нет исходной сцены, модели или ассетов.

Ничего не скачивай.
Начни с пустой Blender-сцены.

ВАЖНО:
главная задача этого эксперимента — не просто смоделировать ретро-компьютер, а создать выразительную PROCEDURAL CHOREOGRAPHY из десятков клавиш + сложное синхронизированное движение камеры.

Это должен ощущаться как короткий high-end motion-design / VFX shot.

Не останавливайся на модели.
Доведи сцену до полностью работающей анимации, камеры, света и финального preview.

==================================================
1. RETRO COMPUTER
==================================================

Создай стилизованный домашний компьютер 1980-х, визуально вдохновлённый Commodore 64, но без необходимости точно копировать историческую модель.

Основные признаки:

— широкий низкий корпус;
— тёплый beige / ivory plastic;
— мягкие скруглённые края;
— углублённая клавиатура;
— тёмно-коричневые / почти чёрные клавиши;
— вентиляционные линии;
— маленький красный power LED;
— аккуратные retro markings.

Компьютер должен выглядеть как качественный product visualization, а не набор примитивов.

Используй bevels и physically plausible materials.

Создай примерно 65–70 клавиш.

КРИТИЧЕСКИ ВАЖНО:

каждая видимая клавиша должна быть отдельным Blender object.

Spacebar также отдельный объект.

Сохрани для каждой клавиши:

HOME_POSITION
HOME_ROTATION

чтобы после сложной анимации абсолютно каждая клавиша могла точно вернуться на своё исходное место.

==================================================
2. VISUAL STYLE
==================================================

Dark cinematic studio.

Компьютер стоит на слегка отражающей тёмной поверхности.

Background:
почти чёрный / dark blue-grey seamless studio background.

Lighting:

— large soft key;
— subtle fill;
— strong controlled rim;
— мягкий pool of light позади компьютера;
— небольшая volumetric atmosphere;
— красивые specular highlights на клавишах.

Корпус должен оставаться тёплым beige.
Клавиши — glossy dark brown / black.

Используй motion blur.

Изображение должно напоминать дорогой product commercial.

==================================================
3. ОБЩАЯ ДРАМАТУРГИЯ
==================================================

Не делай:

клавиши поднялись → превратились в текст.

Это НЕ нужная механика.

Нужная механика:

ASSEMBLED COMPUTER
→ SMALL WAVE
→ ESCALATING CASCADE
→ CONTROLLED ORBITAL CHAOS
→ MAXIMUM SPECTACLE
→ REVERSE REASSEMBLY
→ PERFECTLY ASSEMBLED COMPUTER
→ HERO KEY PRESS / SPARK
→ FINAL GPT ASTRA REVEAL.

То есть компьютер ОБЯЗАТЕЛЬНО должен снова полностью собраться.

==================================================
4. PHASE A — CALM HERO SHOT
frames approximately 1–35
==================================================

Начни с полностью собранного компьютера.

Camera:

низкий cinematic 3/4 front angle.

Примерное ощущение объектива:
50–70 mm equivalent.

Компьютер крупный в кадре.

Камера очень медленно делает dolly-in + едва заметный lateral slide.

Никакой активности первые мгновения.

Дай зрителю понять объект.

==================================================
5. PHASE B — FIRST WAVE
frames approximately 35–70
==================================================

Начни анимацию с левой части клавиатуры.

Первая клавиша:

слегка нажимается вниз
→ резко выстреливает вверх
→ вращается
→ начинает дугообразную траекторию.

Через несколько кадров следующая.

Затем следующая.

Возникает WAVE.

Каскад распространяется:

LEFT → RIGHT

и одновременно немного:

FRONT → BACK.

ВАЖНО:

не поднимай клавиши на одинаковую высоту.

Первые движения сравнительно небольшие.

Следующие становятся всё сильнее.

Создай ощущение:

something is waking up.

==================================================
6. PHASE C — ESCALATION
frames approximately 65–115
==================================================

Теперь амплитуда резко увеличивается.

Клавиши начинают вылетать значительно выше.

Некоторые проходят:

— перед камерой;
— позади компьютера;
— над компьютером;
— по диагонали через кадр.

Используй motion blur.

Spacebar должен стать отдельным HERO OBJECT.

Он вылетает позже основной волны и делает большой медленный rotation в воздухе.

Он заметно крупнее остальных объектов и поэтому должен красиво пересекать композицию.

Но:

НЕ используй неконтролируемую rigid-body simulation как основной механизм.

Все траектории должны быть художественно управляемыми и воспроизводимыми.

==================================================
7. PHASE D — ORBITAL CHOREOGRAPHY
frames approximately 100–155
==================================================

Это главный WOW-момент.

Большая часть клавиш уже находится в воздухе.

Создай несколько организованных потоков движения.

ПРИМЕРНО:

OUTER ORBIT:
часть клавиш летит по большой дуге вокруг компьютера.

INNER ORBIT:
другая группа движется по меньшей противоположной дуге.

CROSSING KEYS:
несколько клавиш пролетают через центр композиции.

HERO SPACEBAR:
вращается через центральную область кадра.

Визуально сверху это должно напоминать:

две спирали / два кольца / vortex choreography.

НО НЕ идеальные математические окружности.

Добавь controlled variation:

— radius;
— height;
— phase;
— tilt;
— rotation;
— speed.

При этом движение должно выглядеть СОЗНАТЕЛЬНО ПОСТАВЛЕННЫМ.

Не как взрыв.

Не как мусор в zero gravity.

Это choreography.

==================================================
8. CAMERA CHOREOGRAPHY
==================================================

КАМЕРА — ОДИН ИЗ ГЛАВНЫХ ГЕРОЕВ РОЛИКА.

Не оставляй её в одном положении.

Создай единое плавное движение камеры, синхронизированное с интенсивностью клавиш.

START:

low 3/4 front product shot.

Во время первого каскада:

camera slowly trucks sideways и немного приближается.

Когда клавиши начинают активно летать:

camera начинает CRANE UP.

Одновременно:

camera ORBITS вокруг компьютера примерно на 25–45 градусов.

К кульминации:

перейди к гораздо более высокому 3/4 top view.

Компьютер теперь виден сверху,
а траектории клавиш становятся читаемыми как огромные дуги вокруг него.

В максимальной точке хаоса:

camera продолжает медленный orbital move.

Используй foreground parallax:
несколько клавиш должны пролететь близко перед объективом.

Это даст ощущение масштаба и глубины.

DO NOT:
— teleport camera;
— делать резкие необоснованные cuts;
— проходить камерой через geometry.

Camera movement должен ощущаться как один дорогой continuous commercial shot.

==================================================
9. PHASE E — REVERSE COLLAPSE
frames approximately 145–195
==================================================

Теперь движение начинает организованно схлопываться.

Все клавиши возвращаются к клавиатуре.

ВАЖНО:

это не просто reverse playback.

Пусть сначала:

outer orbit collapses,
затем inner orbit,
затем отдельные hero keys.

Каждая клавиша должна попасть ТОЧНО в собственный HOME_POSITION и HOME_ROTATION.

Никаких:

— floating keys;
— неправильных мест;
— intersections;
— rotated keys после посадки.

Добавь небольшое settle:

arrival
→ tiny overshoot
→ final seating.

Spacebar садится одной из последних.

К концу этой фазы компьютер должен снова выглядеть ПОЛНОСТЬЮ СОБРАННЫМ.

==================================================
10. CAMERA DURING REASSEMBLY
==================================================

Одновременно камера начинает опускаться обратно.

Из high 3/4 top view она приходит к более фронтальному ракурсу.

Когда последние клавиши садятся:

камера делает controlled push-in к клавиатуре.

Это должно создать переход:

BIG SPECTACLE
→ INTIMATE DETAIL.

==================================================
11. HERO KEY MOMENT
frames approximately 195–215
==================================================

После полной сборки сделай короткую паузу.

Примерно 6–10 кадров относительного спокойствия.

Затем одна центральная клавиша активируется.

Она:

слегка нажимается вниз.

В момент нажатия:

— яркий white-blue emissive flash;
— небольшой burst золотисто-белых sparks;
— короткий bloom;
— subtle light response на соседних клавишах.

Именно это событие запускает финальный reveal.

Камера в этот момент находится достаточно близко к клавиатуре.

==================================================
12. FINAL REVEAL
frames approximately 210–260
==================================================

После вспышки камера начинает плавно отъезжать и немного подниматься.

ПОЗАДИ компьютера появляется крупная светящаяся pixel typography.

Текст:

READY.

а следующей строкой:

GPT ASTRA

Финальная композиция:

             READY.

           GPT ASTRA █

       [ RETRO COMPUTER ]

Используй отдельную 3D pixel typography.

НЕ используй клавиши компьютера для формирования текста.

Клавиатура в финале должна оставаться полностью собранной.

Typography:

retro computer bitmap aesthetic;
bright white;
subtle cool tint;
soft bloom;
небольшое volumetric glow.

После ASTRA:

маленький квадратный cursor █

должен мигнуть 1–2 раза.

==================================================
13. CAMERA FOR FINAL REVEAL
==================================================

Финальная камера должна дать сильный HERO SHOT.

Компьютер занимает нижнюю часть кадра.

READY. / GPT ASTRA располагаются над ним.

Используй достаточно низкий угол, чтобы текст ощущался большим и физически присутствующим в пространстве.

Camera gently settles.

Последние ~1–1.5 секунды почти статичны.

Только:

cursor blink,
очень слабое движение haze,
остаточное свечение.

==================================================
14. ANIMATION QUALITY
==================================================

Очень внимательно работай с easing.

НЕ используй одинаковую linear interpolation для всех объектов.

Для вылета:

fast acceleration + smooth arc.

Для orbit:
smooth continuous motion.

Для возвращения:
fast approach + tiny overshoot + settle.

Разнеси timing отдельных клавиш.

Избегай ощущения:

“65 объектов получили одинаковую анимацию со сдвигом на 2 кадра”.

Нужна controlled irregularity.

==================================================
15. PROCEDURAL IMPLEMENTATION
==================================================

Используй Blender Python там, где это рационально.

Создай данные для каждой клавиши:

home_location
home_rotation
launch_delay
orbit_radius
orbit_height
orbit_phase
rotation_speed
return_delay

Используй deterministic random seed.

Результат должен быть воспроизводимым.

Предпочитай математически управляемые trajectories вместо chaotic physics.

Если используешь curves / constraints / empties — организуй их понятно.
